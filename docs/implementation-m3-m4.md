## Decisions

- Variables are case-sensitive ASCII identifiers `[A-Za-z_][A-Za-z0-9_]*`, held in dictionaries compatible with the existing empty globals object. Request overrides collection, then global. No recursive expansion; only effective referenced values decrypt. Unused/shadowed secrets do not require Keychain access.
- Exact `{{name}}` tokens substitute once. `\{{name}}` emits literal `{{name}}`; a bare closing `}}` remains ordinary text, including nested JSON. Invalid/unclosed opening tokens are errors. Values introduced by substitution are never parsed again.
- URL template substitution is literal and may supply URL structure (for example base URL). Query-table and path-value substitution happens before their existing encoding. Path parameters encode one complete segment. Headers/auth/body substitute literally, without implicit JSON escaping or formatting. Inactive fields do not resolve.
- Structured Basic/Bearer plus an enabled Authorization header is an error after substitution, case-insensitive. None preserves manual header behavior. Basic uses UTF-8, rejects colon in username/control characters; Bearer must be nonempty and contain no whitespace/control characters.
- Persist only encrypted password/token inputs and marked-secret variables; ordinary literals remain plaintext. Auth templates can themselves be encrypted. Inactive encrypted auth fields may remain stored for switching modes but are not decrypted for execution.
- AES-256-GCM, fresh CryptoKit nonce, versioned Base64 combined sealed box, one Keychain app key, no custom cipher/rotation/record binding. Missing/denied key preserves ciphertext and blocks affected operations. No replacement key if ciphertext exists or damaged/unsupported storage makes that uncertain. UI plaintext edit buffers are transient; seal succeeds before updating persisted models. No plaintext fallback.
- Persisted configuration remains templates/ciphertext. Non-Codable PreparedHTTPRequest carries URLRequest and effective inputs in memory. HTTP results retain original configuration, not resolved plaintext configuration. Existing observed headers/response files can contain plaintext under the agreed local-user policy.
- Store writes replace owned variable maps and known auth fields appropriately. Generic unknown-field merging must not resurrect deleted variable names or obsolete plaintext. Preserve unrelated unknown metadata and unsupported documents.
- Highlighting uses native AppKit text presentation, shares template/path grammar, and preserves selection/undo/IME. None suppresses JSON colors but retains variable/path/missing cues. Missing cues use names/metadata, not Keychain reads. Raw/Pretty never changes source response bytes; full formatting cap5MiB, raw preview1MiB. Formatting/highlight work is bounded and off-main where practical.
- Auth/Variables tabs, Global Variables sidebar and collection-scope access follow native controls. Keep monospace protocol/value inputs and natural body height. Palette matches stored/draft name or literal URL/path, deterministic ordering, stable identity and no sending/secret resolution.
- Test main functional requirements, not comprehensive coverage. Use synthetic loopback data/isolated directories and dedicated newly created validation Keychain service identifiers only; do not enumerate/read existing user keys, config, environment or PII. Ad-hoc signing continuity requires actual verification and honest reporting; no broad ACL weakening.
- Keep commits local, per explicit user preference. No push.

## Interfaces and ownership

Main owns ConfigurationValues.swift/Models.swift, AppModel integration, ContentView/menu integration and durable docs. Bounded workers own crypto/preparation/persistence/native editor surfaces as assigned. Shared declarations in ConfigurationValues.swift are frozen before delegation. VariableValue encodes ordinary values as JSON strings and encrypted values as SecretEnvelope objects; request/collection/globals additive fields default empty/None. Store public additions: saveGlobalVariables(_:) and saveCollectionVariables(_:in:).

Completed delegation: m34_app_integration owned AppModel/VariableOwner/lifecycle tests; m4_native_highlighting owned native body/field/response text; m34_auth_variable_ui owned request/auth/variable editors. Main owned search, response formatting, shared models and integration. Separate core/security and UI reviewers, independent tester and repository explorer supplied final gates. No actual Keychain access occurred in automated tests; native validation used only new dedicated synthetic services.

Primary references checked 2026-10-17: [CryptoKit AES.GCM](https://developer.apple.com/documentation/cryptokit/aes/gcm), [Mac Keychain implementations](https://developer.apple.com/documentation/technotes/tn3137-on-mac-keychains), [temporary layout attributes](https://developer.apple.com/documentation/appkit/nslayoutmanager/addtemporaryattributes(_:forcharacterrange:)). ## Review and verification, 2026-10-17

- Independent core/security review found no substantiated release blocker. Independent UI review found request/owner state reuse, a second debounce losing ordinary edits at quit/reversion, and editable inputs during asynchronous secret operations. All were corrected and independently rechecked. Secrets use explicit Save/Cancel; leaving a request/scope discards unsaved secret edits, stated beside the controls. Same-request tabs retain their buffers.
- Initial full-suite failures exposed workspace publication before vault readiness; corrected atomic publication and initial-load ordering without weakening existing tests. Independent `make test` subsequently passed 66 tests: Core53/App13, zero failures. Tests use fake keys, synthetic stores and loopback HTTP only. A held-key preparation test covers cancellation/deletion model ownership; its fixture has no endpoint-hit counter, so it is not a direct zero-network-requests proof.
- Release packaging and strict signature verification passed. Native checks use unique validation bundle IDs plus explicit synthetic data/body directories, never existing runtime configuration. Native creation of a new Keychain application key, Bearer send, ordinary-to-secret conversion and same-binary restart/decryption passed. Inspection of synthetic saved request JSON confirmed ciphertext for the converted value/token and no duplicate literal token. Ordinary variable edit followed immediately by quit survived restart.
- Replacing/resigning the ad-hoc executable prompted macOS for access to the synthetic key; the user reported approving it. Unattended continuity across rebuilt binaries is not established. Do not weaken default Keychain ACLs; stable distribution signing remains future release work. No existing user keys were queried. The automation tool blocks macOS UserNotificationCenter dialogs, so removable-volume permission prompts require the user to click Allow; it cannot enter a login password.
- Native loopback output confirmed scope values, path encoding, template body and structured Bearer header. Command-K mixed-case URL/path match, arrow/Return open without sending, no-match state and Escape restoring body selection/focus passed. None preserved template cues while removing JSON colors; syntax changes preserved native body undo. Dark native colors, collapsed header groups and one vertical scroll owner per pane were visually checked against v3 at the minimum window size. Final compact-control label fix removed a tall gap.
- Native quick-entry checking found a regression from using SwiftUI FocusState with unregistered native controls, plus doubled field glyphs while editing. Repairs use State, guard queued focus transitions and suppress idle cell text while the field editor draws. Final native recheck passed full trailing header entry, Tab through values/next row, no hidden-field typing after switching tabs, and single URL rendering with red missing-variable/path cues. The variable-source footer showed Global/Collection/Request precedence and Secret metadata without unlocking values.

Synthetic test artifacts remain outside the repository; no user configuration/credentials were read. One automatic stale-process cleanup review timed out; a verified single retry succeeded, leaving no cleanup blocker.
